# OmniSorSe Explorer Protocol v1 contracts

This project mirrors the public, dependency-free contracts shipped in OmniSorSe v2.4.0 tag `v2.4.0` at commit `40552b9b2b18637313354713d66593d04cf0d92f`.

It contains only the versioned wire DTOs and enums. It contains no OmniSorSe storage, search, indexing, application, transport-host, or UI implementation. Changes must be checked against the authoritative shipped contract before the protocol version is changed.
