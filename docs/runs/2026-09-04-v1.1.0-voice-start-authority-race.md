# v1.1.0 Voice start authority-race review

## What this run was meant to do

Independently challenge the completed v1.1.0 candidate at `ac0b802020ed9395f26774f26867d9e98dc280c8` before hosted qualification, with preservation of the local implementation as the first priority and no publication action.

## What actually changed

The review found one release-blocking Voice race. Cancelling Voice, or replacing the active provider, while the lazy speech capability check was still running could allow that obsolete start operation to proceed into microphone capture. The coordinator now establishes cancellation and captures provider authority before the capability check, rejects cancellation immediately after asynchronous capability work, and verifies that authority is still current before starting capture. Two deterministic regressions hold the capability check open while cancellation or provider replacement occurs and prove that capture never starts.

Current release documentation now records the correction, distinguishes exact automated install/upgrade evidence from pending manual gates, and removes two resolved engineering-lesson gaps whose executable coverage already existed in the candidate.

## Important technical decisions

- **Decision:** Treat capability discovery as part of the Voice operation rather than as pre-operation setup. **Why:** it is asynchronous, user-cancellable work that runs before access to privacy-sensitive hardware. **Impact:** the same linked cancellation and captured provider context now govern the entire start path.
- **Decision:** Preserve the existing click-to-toggle behavior and bundled Voice architecture. **Why:** the defect was an authority-timing race, not a product-design failure. **Impact:** no feature or public interface was removed to make validation pass.
- **Decision:** Keep hosted and manual qualification out of this historical snapshot. **Why:** recording those results in the source commit after they run would change the commit being qualified. **Impact:** workflow records and the final owner report remain the authority for post-push evidence.

## What the agents learned

The earlier stale-result tests correctly protected completed transcription but did not prove that privacy-sensitive capture itself could not begin after authority changed. The durable form is the pair of held-capability regression tests plus the coordinator ordering, not an additional global rule. Existing provider-aware navigation and resource-driven contrast regressions were independently present and passing in the reviewed candidate, so their previously retained candidate lessons could be promoted.
