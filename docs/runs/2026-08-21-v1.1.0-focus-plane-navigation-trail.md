# v1.1 focus-plane navigation-trail convergence

## What this run was meant to do

Resolve owner issues #1–#7 as one coherent OmniBrille interaction system: truthful hierarchy, ordinary-user local Voice, distinct Back/Up/Root/history navigation, a borderless concept-led shell, bounded spatial motion and density, terminal-style Details, safe file activation, and optional interaction sound. Preserve the one `ExplorerSession`, bounded-scene, stale-result, accessibility-projection, privacy, and Standalone-versus-Connected authority invariants. Publish nothing unless exact installed, accessibility, hardware, performance, security, signing, and hosted gates all pass.

## What actually changed

OmniBrille now uses a **Focus Plane + Navigation Trail** model. Every admitted structural child is semantically a direct child of the current focus; the renderer's inner/middle/outer `PresentationBand` affects density only. The center remains dominant, admitted files/folders stay recognizable glyphs, targets are at least 44 DIP, labels use the palette's contrast-qualified text color, and graph/list/Details/UIA share explicit scene relations.

The shell now has distinct pointer, keyboard, Voice, and automation paths for Back, provider-authored Up, authority Root, and a bounded human-safe Trail. New scenes start without an inferred selection, so Details opens only after explicit selection/reopen. Search, Trail, Connection, and Details share one right-plane authority. Arrow keys use geometric direction. Custom borderless chrome retains explicit window controls and a drag/double-click title strip.

Graph motion is analytic and bounded around immutable layout coordinates: deterministic low-amplitude float, local hover lens, transition continuity, one approximately 24-fps foreground ticker, and immediate Reduced Motion shutdown. Details exposes complete semantic text atomically while its optional visual projection types. Locally generated bounded sound is redundant, debounced, master-muted, and device-failure independent.

The Windows installer path now owns a pinned whisper.cpp v1.9.2 CPU runtime and `ggml-base.en-q5_1` model. Build, package, manifest, and application gates bind the official archive/model and installed runtime-file hashes. Click once listens; click again stops/transcribes. Grammar includes Back, Up, Root, visible-node focus/open, and open-selected variants. Process environment/output/time/thread count and JSON are bounded; timeout/cancellation terminates and awaits the process tree before zero/retry cleanup in a local non-reparse workspace. Voice failure leaves all nonvoice paths usable.

Standalone file activation revalidates selected-root containment, existence, reparse ancestors, and a broad high-risk Windows type denial immediately before structured shell activation. Connected projected paths are never file authority. Large standalone enumeration/Search work is capped, and projection after the first 512 entries is coalesced to every fourth 128-entry batch plus the final state.

## Important technical decisions

- **Scene relation and presentation density are separate types** → radius/opacity previously masqueraded as filesystem depth → all projections can state current focus, direct child, previous focus, Context, both, or aggregate without deriving authority from visuals.
- **Back, Up, and Root are different session operations** → history, containment, and authority root are different concepts → Connected Up/Root continue to use opaque provider targets and never display paths.
- **Motion remains analytic rather than simulated** → continuous force/layout work would undermine bounded deterministic rendering → membership, topology, ordering, selection, and acquisition remain stable and timer ownership stays explicit.
- **One general polite status authority** → visual panels can hide or duplicate status text → accepted current work changes one queryable automation name while feature-local regions remain scoped.
- **Installer-owned, exact-hash Voice bundle** → manual runtime/model paths did not serve ordinary users → first use is local/offline after install, with Advanced overrides removed from the normal path and supply-chain provenance explicit.
- **File activation stays Standalone-only** → Explorer Protocol v1 has no host-authorized Connected file-open operation → Connected failure is truthful instead of falling back to local filesystem interpretation.
- **Sound and visual typing are projections, never state owners** → sensory failure/preferences must not alter navigation → mute, Reduced Motion, device failure, and rapid replacement retain identical session outcomes.

## What the agents learned

The initial assumption that seven issue tickets could be handled as adjacent UI fixes was wrong; hierarchy, navigation, selection, accessible projection, motion, Voice packaging, and sensory feedback share one state/authority contract. Design/UX, accessibility, and security/resource specialists were all justified and found different P1 failures after the first green build. Their highest-value contribution was adversarial convergence review after implementation, not parallel editing.

Promoted durable lessons:

- **Presentation density must never carry semantic hierarchy** → independently reproduced by issue evidence and accessibility/design review → promoted to explicit types, graph/list/UIA parity tests, architecture, and `interaction-state-contract.md`.
- **Terminate and await native children before sensitive temp cleanup** → security review reproduced the Windows race → promoted to process-runner/provider tests, fail-closed cleanup, and security/Voice documentation.
- **Test renderer-effective contrast, not copied literals** → two reviewers found palette/opacity failures missed by the old test → promoted to source-parsed `ScenePalette` compositing tests.
- **Floating panels need one executable surface authority** → Search, Details, Connection, and Trail each exposed collisions → promoted to explicit arbitration and regression tests.
- **A visible navigation label must invoke the same authority operation across pointer/keyboard/Voice** → ROOT violated this while tests enshrined the wrong name → promoted to shared session action and pointer parity test.

Remain candidate: replace the high-risk file extension denylist with an ordinary-document/media allowlist after product review of expected file types; current denial is materially stronger but native association testing is still required. Rejected: treating headless UIA, simulated text scale, source screenshots, or the known-WAV transcription as certification for screen readers, OS scale, final visuals, or live microphone behavior.

No new global `AGENTS.md` rule was added; the executable contracts and subsystem documentation are more precise and cheaper to maintain.
